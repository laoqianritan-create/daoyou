# daoyou · 空间考古导游

> 给任何一栋建筑、一条街道、一个街区做「空间考古」：它现在是什么 → 它曾是什么 → 一层层怎么变到今天 → 标签底下压着什么。

一个 Agent Skill（Claude Code / Hermes / 其他支持 `SKILL.md` 的 Agent 都能用）。
它把「空间即地质剖面」这个观察方法，变成一套可执行、可核查的考古流程。

## 心法

1. **此刻＝地质剖面**：今天看到的任何空间景观，只是历史故土堆的最表层，由过去一层层演化至今，而且过程永不停。
2. **没有小地方，只有没钻进去的地方**：任何不起眼的角落都是「孔洞」，钻过去＝另一个世界。不到十条街的西塔，能叠出四百年东亚史。
3. **打捞叙事收编不了的复杂性**：名片、标签、网红词都是后贴的。祛魅它们，挖被压掉的那一层。

## 八层考古框架

自底向上，每层问一句「这一层在这片地上留下了什么痕迹」：

| 层 | 看什么 |
|---|---|
| 1 自然地理层 | 原初地貌（河 / 湖 / 坡 / 城墙外），名字来历 |
| 2 信仰 · 宗教层 | 塔 / 寺 / 教堂 / 庙 / 神祠——最早的「意义装置」，常是地名来源 |
| 3 权力 · 治理层 | 皇家工程、行政区划、驻军、官府——谁在此立过规矩 |
| 4 交通 · 基础设施层 | 铁路 / 公路 / 运河 / 码头 / 城门——交通决定人在哪落脚 |
| 5 经济 · 产业层 | 作坊 / 工厂 / 市场 / 商业资本——产业兴衰 |
| 6 人群 · 移民层 | 谁来了、谁走了、聚居与离散、冲突与融合 |
| 7 政治 · 意识形态层 | 战争 / 殖民 / 改造 / 运动——大时代怎么碾过小地方 |
| 8 消费 · 符号层 | 名片 / 旅游化 / 网红化 / 复建与仿古——今天的那层皮 |

## 安装

把整个目录放进 Agent 的技能目录即可，只有一个 `SKILL.md` 加一份变更日志，无第三方依赖、无 API key：

```bash
# Claude Code
git clone https://github.com/laoqianritan-create/daoyou.git ~/.claude/skills/daoyou

# Hermes
git clone https://github.com/laoqianritan-create/daoyou.git ~/.hermes/skills/daoyou
```

## 用法

```
daoyou 宽窄巷子
daoyou 上海武康大楼
导游一下 北京卧佛寺
帮我把这条街考古一遍：<地名 / 照片 / 一句话描述>
```

## 你会拿到什么

一份「空间考古档案」，固定八节：

1. 现状与名片
2. 层皮剖面（自底向上）
3. 编年时间线
4. 标签祛魅
5. 世界时间坐标
6. 线头（值得讲的人 / 事 / 物）
7. 待考清单
8. 材料索引

## 四条纪律

- **不编造**：材料没给的年份、事件一律进「待考清单」，不写「大概」「应该」。
- **来源可溯**：每条史实标来源，方便回查。
- **一手史料优先**：地方志、古籍原文 > 现代综述 > 旅游自媒体；冲突以原文为准，并把冲突记进待考清单。
- **传说与史实分层**：民间传说照记，但必须标注「传说层」。
